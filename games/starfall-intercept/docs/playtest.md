# Starfall Intercept MVP Playtest

這份指南針對目前已完成的三波固定波次 MVP。它不是後續功能清單；請只記錄實際看到的結果，不要把尚未完成的 Boss、滑鼠、觸控、商店或其他擴充功能列為預期行為。

## 測試前準備

在終端機執行：

```bash
cd /Users/chenchungnien/code/phaser-games/games/starfall-intercept
npm install
npm run dev
```

在瀏覽器開啟 `http://127.0.0.1:5173/`。建議使用最新版 Chromium-based 瀏覽器，並使用實體鍵盤；目前 MVP 只支援鍵盤，不支援滑鼠、觸控或手把。

可先另開一個終端機執行自動規則測試：

```bash
npm test
```

若要檢查正式打包是否成功，可執行 `npm run build`。人工測試仍應以瀏覽器中的實際遊戲畫面為準。

## 目前操作

| 操作 | 功能 |
|---|---|
| `Enter` | 開始遊戲；在 `GAME OVER` 或 `MISSION COMPLETE` 重新開始 |
| `A` / `D` | 玩家向左／向右移動 |
| 左／右方向鍵 | 玩家向左／向右移動 |
| 按住 `Space` | 持續發射玩家雷射 |

玩家只能水平移動。分數、目前波次與生命會顯示在畫面上方。MVP 沒有背景音樂；音效是否播放取決於瀏覽器對 OGG 的支援，但音效不應阻止遊戲操作。

## 測試紀錄格式

每個步驟完成後填寫一行或一段：

```text
測試編號：
是否完成：是／否／部分完成
是否符合預期：是／否／不確定
實際發生：
功能問題：無／有（請描述可判定的錯誤）
體驗觀察：
嚴重程度：阻斷／明顯問題／輕微問題／體驗建議
```

「阻斷」表示無法繼續遊戲或核心流程無法完成；「明顯問題」表示仍可玩但結果錯誤或嚴重影響遊戲；「輕微問題」不影響主要流程；「體驗建議」表示功能沒有明確錯誤，但手感、節奏、資訊或回饋可以改善。

## 依序完成一局遊戲

### 1. 啟動、載入與開始畫面

**操作：** 開啟網址並等待載入完成，不按任何鍵。

**正常結果：** 先看到載入進度，之後進入 `STARFALL INTERCEPT` 選單，畫面列出移動、射擊與 Enter 開始提示。

**同時觀察：** 標題、字體與提示是否清楚；背景是否完整顯示；瀏覽器 Console 是否出現例外、素材載入錯誤或 404。

### 2. 進入第一波

**操作：** 按一次 `Enter`。

**正常結果：** 選單切換到遊戲畫面，玩家飛船出現在底部，HUD 顯示 `SCORE: 000000`、`WAVE 1/3` 與 `x3`，短暫顯示 `WAVE 1`。

**同時觀察：** 是否能在約 30 秒內理解玩家位於底部、威脅從上方下降、需要射擊與閃避；畫面是否有足夠的空間辨識玩家和敵人。

### 3. 測試水平移動與邊界

**操作：** 分別按住左方向鍵、右方向鍵、`A`、`D`；接著持續向左或向右按到畫面邊界，再放開按鍵。

**正常結果：** 玩家立即向相應方向移動，只能左右移動，不會離開畫面；放開後停止。`A/D` 與左右方向鍵應有相同效果。

**同時觀察：** 移動速度是否容易控制；放開按鍵後是否會多滑一段；飛船是否容易和下降中的敵人或隕石對齊；邊界是否讓玩家感覺被截斷或不公平。

### 4. 測試射擊與冷卻

**操作：** 按住 `Space`，讓綠色玩家雷射持續向上發射；再快速重複按放 `Space`。

**正常結果：** 會看到 `laserGreen04.png` 向上移動；射擊不會每幀無限產生，正常射速有可辨識的間隔。若瀏覽器支援 OGG，成功射擊會播放低音量雷射音效。

**同時觀察：** 雷射是否容易追蹤；按住和快速連按是否都容易理解；射擊音效是否太大、太密或完全沒有回饋。

### 5. 第一波的命中、得分與清波

**操作：** 持續射擊並左右移動，嘗試命中第一波的 Scout 與小棕隕石。

**正常結果：** Scout 被擊破後增加 100 分；小隕石被擊破後增加 25 分；第一波所有威脅消失或穿越底部後，分數再增加 250，短暫顯示 `WAVE CLEAR +250`，接著自動進入第二波。

**同時觀察：** Scout 與隕石是否容易分辨；命中和擊破是否能從消失、分數與 zap 音效理解；玩家是否知道自己應優先射擊哪個目標。

### 6. 第二波的 Gunner、敵方雷射與中隕石

**操作：** 在第二波繼續射擊與閃避，特別留意綠色 Gunner 和紅色敵方雷射。

**正常結果：** 第二波包含 Scout、Gunner、小隕石與中隕石。Gunner 會先下降，再做簡單水平往返並定期向下發射 `laserRed04.png`。中隕石比小隕石更耐打，擊破後增加 50 分；Gunner 擊破後增加 200 分。

**同時觀察：** Gunner 的橫移和敵彈是否真的形成不同決策；紅色雷射是否看得見；敵人密度是否仍可讀；玩家是否知道受傷來自哪一種威脅。

### 7. 實際承受傷害與無敵回饋

**操作：** 故意讓敵人、隕石、敵方雷射或漏過底部的威脅造成一次傷害。不要連續撞擊同一個位置太久。

**正常結果：** HUD 的生命從 3 變成 2 或從 2 變成 1；玩家短暫閃爍，約一秒內不會因同一連續碰撞重複扣血。生命歸零時會進入 `GAME OVER`。

**同時觀察：** 受傷原因是否容易理解；生命變化是否足夠醒目；閃爍是否太快、太慢或造成不適；漏怪扣血是否有足夠的畫面與聲音提示。

### 8. 取得第二波 Bolt（Rapid Fire）

**操作：** 在第二波留意從上方下降的藍色 Bolt power-up，移動到它的路徑上取得它，接著按住 `Space`。

**正常結果：** 道具與玩家重疊後消失，短暫顯示 `RAPID FIRE`；約 6 秒內玩家雷射冷卻縮短，之後恢復普通射速。道具不增加分數。

**同時觀察：** 道具是否容易看見；玩家是否能理解它已被取得；射速差異是否足夠明顯但不會造成畫面混亂；移動去撿道具是否值得承擔風險。

### 9. 第三波 Shield 與一次性吸收

**操作：** 完成第二波進入第三波，移動到藍色 Shield power-up 的路徑上取得它。取得後故意讓一次敵彈、敵人或隕石碰到玩家。

**正常結果：** 取得時顯示 `SHIELD READY`，玩家周圍出現 `shield1.png` 視覺；第一次有效傷害由護盾吸收，生命不下降，護盾消失並顯示 `SHIELD ABSORBED HIT`。之後再次受傷才會扣生命。

**同時觀察：** 護盾是否清楚表達「只剩一次」；吸收傷害的回饋是否容易察覺；玩家是否能做出「保留護盾還是冒險撿道具」的決定。

### 10. 完成第三波與勝利

**操作：** 清除第三波的 Scout、Gunner、大隕石與中隕石，持續移動並射擊直到所有威脅處理完畢。

**正常結果：** 第三波清除後再增加 250 分，進入 `MISSION COMPLETE`，畫面顯示 `PRESS ENTER TO RESTART`。勝利後不應再生成新威脅或繼續受到傷害。

**同時觀察：** 玩家是否清楚知道為什麼勝利；高密度畫面是否仍能看見敵彈、玩家與道具；完成一局所需時間和壓力是否合理。

## Game Over 與 Restart

### 11. 觸發 Game Over

**操作：** 重新整理頁面、按 `Enter` 開始，但這次不要射擊，讓威脅撞擊、漏過底部或敵彈逐步消耗三條生命。

**正常結果：** 生命降到 0 後顯示 `GAME OVER` 與 `PRESS ENTER TO RESTART`。結果畫面停止敵人生成、敵方射擊、玩家移動、射擊與得分變化；Console 不應新增錯誤。

**同時觀察：** 玩家是否知道自己為什麼失敗；Game Over 是否太突然；結果畫面是否有足夠的結束感而沒有遮住關鍵資訊。

### 12. Restart 與狀態重置

**操作：** 在 Game Over 按一次 `Enter`。確認新局開始後，再讓它進入 Game Over，連續重複 Restart 至少兩次。若已完成勝利，也在 `MISSION COMPLETE` 按 `Enter` 重做一次。

**正常結果：** 每次新局都回到第一波、分數 0、生命 3、沒有 Rapid Fire、沒有 Shield、玩家回到底部；舊敵人、舊雷射、舊 Timer 不應殘留或加倍。第二次、第三次 Restart 的行為應與第一次相同。

**同時觀察：** 重開是否立即且容易理解；是否出現敵人數量逐局增加、音效重複、波次跳號、HUD 疊字或輸入延遲。

## 少量邊界測試

只執行與目前 MVP 直接相關的情況：

1. 持續向左或向右按住，確認玩家不會出界；到邊界後快速交替左右鍵，確認不會卡住或反向失控。
2. 短時間連續按放 `Space`，確認射擊冷卻仍生效，不會產生無限雷射或 Console 錯誤。
3. 在生命剩 1 時故意承受一次傷害，確認立即進入 Game Over；在 Game Over 後繼續按方向鍵與 Space，確認不會恢復遊戲動作。
4. 取得 Shield 後同時接近多個威脅，觀察一次有效碰撞只消耗一層護盾，且不會因同一瞬間重複扣除多條生命。
5. 在結果畫面快速連按兩次或三次 `Enter`，確認只建立一個乾淨的新局，沒有倍增的生成、Timer 或音效。

## 自由遊玩

完成指定步驟後，不看上面的操作提示，自由玩 3–5 分鐘或直到完成一局。請按照你自然理解的方式移動、射擊、閃避與取道具，不要刻意為了測試每一個功能而打斷遊戲。

自由遊玩時請記錄：

- 是否自然理解目標是清除三波並存活，而不是只躲避或只撿道具。
- 什麼時候開始不知道下一步要做什麼，或不知道自己為什麼受傷、失敗、進入下一波。
- 哪一種敵人、敵彈或道具最容易被忽略。
- 什麼時刻最有趣、最緊張或最有成就感；什麼時刻最無聊、混亂或挫折。
- 操作是功能正確但不舒服，還是根本沒有按預期工作。

請把「功能問題」和「體驗問題」分開。功能問題要描述可以判定對錯的結果，例如按鍵無反應、素材不顯示、碰撞沒有扣血、分數不更新、Game Over 不停止或 Restart 留下舊敵人。體驗問題請描述具體情境，例如「第二波兩個 Gunner 同時射擊時，紅色雷射和背景對比不足，無法判斷該往哪邊閃」，不要只寫「太難」或「不好玩」。

## 整體回饋

1. 你是否能在大約 30 秒內說出遊戲目標？如果不能，卡在哪個畫面或資訊？
2. 哪一個操作最難理解或最不容易控制？請描述實際情境。
3. 哪一個時刻最有趣或最有成就感？當時你做了什麼？
4. 哪一個時刻最困惑或最挫折？你當時以為會發生什麼？
5. 你是否清楚知道自己為什麼成功或失敗？哪個回饋不足？
6. Scout、Gunner、隕石、Bolt、Shield 中，哪一項機制最有價值？為什麼？
7. 哪一項內容目前最沒有必要？刪除它會不會影響核心樂趣？
8. 你是否願意再玩一次？是因為想挑戰更高分、想嘗試不同閃避與射擊，還是其他原因？
9. 如果現在只能修改一件事情，你最希望修改什麼？原因是什麼？
